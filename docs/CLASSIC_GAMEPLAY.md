# 经典模式改造主线

经典游戏 `/` 是后续改造的主入口，保留原有地图、物种、神力、基因和谱系玩法。
`/play` 与 `/lab` 的独立模型只保留为实验入口；它们已有的功能不能算成经典模式已完成的迁移。

## 本轮落到经典游戏的改动

- 修复物种列表刷新抹掉回合解释数据：实时名称、状态、人口覆盖旧值；出生、死亡、压力、叙事和生态信息保留真实回合记录。
- 自动演化每完成一回合就更新报告和世界，不再等整批结束才显示。后续请求失败时，已返回的回合仍保留在界面。
- 原有推演进度窗增加“本回合结束后暂停”。当前请求完成后停止后续回合，不用重置AI连接假装暂停模拟。
- 原有回合总结增加最多三个重点物种卡，直接定位物种；人口不再标成生物量，分化谱系去重，缺少连续记录时不把历代灭绝全算进本回合。
- 修复经典引擎构造 `ConfigService` 时缺少参数的问题，让回合读取实际设置。
- 修复空库初始化访问不存在的栖息地/扩散容器属性，并保留已配置的同一个模型路由实例。
- 移除经典页面上通向独立沙盒的悬浮推广入口。

修改集中在 `App.tsx`、`GameProvider.tsx`、原有进度/总结弹窗，以及经典 `simulation/engine.py` 和 `core/container.py`。
新文件是经典回合操作hook、暂停控件和重点物种卡；没有替换经典地图或另起游戏页面。

## 边界与后续

经典模式仍使用原有模拟管线和存档。新种子系统、原子提交、checkpoint/delta和AIJob尚未整体接入经典引擎。
Qwen目前通过经典ModelRouter调用；本轮修复配置读取不等于已经完成AI与模拟解耦。
后续按经典实际调用链迁移这些底层能力，不要求玩家换到独立沙盒。

按用户要求，本轮没有新增或运行测试、lint、typecheck、构建、长跑或游戏验收；未测量性能。
逐回合界面更新会比原来整批更新增加读取请求。存档格式未改，旧记录缺少的信息不会补造成历史事实。
