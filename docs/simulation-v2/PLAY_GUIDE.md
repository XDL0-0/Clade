# 生命演化沙盒

打开 `/play` 开始游玩。旧地址 `/lab` 也能进入；经典模式首页右下角有新入口。

## 先玩一局

1. 点 **开始新世界**。默认自动生成世界种子，想重玩同一个开局时可以展开“自定义世界”。
2. 选一个感兴趣的物种并加星关注，在地图上查看它的分布。
3. 点 **推进 10 回合**。也可选择 1 或 50 回合；暂停会等当前回合保存后停下。
4. 试试 **暖化、冰河、灾变**。它们改变生存环境，物种的命运由模拟决定。
5. 拖动 **时光机** 查看过去，点 **从这里开启另一种未来** 创建分支。
6. 在 **平行世界** 中选择情景，同时保留原环境与变化后的世界，再进入喜欢的分支继续玩。

暖化和冰河改变后续气候趋势，温度逐步响应。灾变只施加一回合压力，之后可以观察恢复。
星标只是你的关注列表，不会给物种加成。世界纪事来自真实事件；没有演化记录时不会编造升级。

## 保存和继续

每回合自动保存。重新打开页面会记住最近游玩的世界；历史可以随时查看。
网络中断后用“取回上一回合”恢复那次操作，再决定是否继续快进。
平行世界的未完成计划保存在当前浏览器会话中，可以继续同一个计划。

物种性状决定外观示意。详细性状、世界比较、性能信息都在折叠面板里，游玩不需要调这些参数。

## 启动

在已装好项目依赖的环境中，启动独立后端：

```bash
cd backend
python -m app.api.v2 --root ./data/simulation-v2 --port 8022
```

另开一个终端启动前端：

```bash
cd frontend
BACKEND_PORT=8022 npm run dev
```

打开 Vite 给出的地址并加上 `/play`。原应用启动方式也挂载了新 API。
当前这套运行环境使用 Linux/glibc x86-64。经典模式与旧存档使用原有入口，新沙盒单独保存。

## 当前进度

这是新模拟核心的可玩入口，经典模式尚未整体切换。真实 LLM 叙事需要单独配置；没有配置也可以看世界纪事并完整推进模拟。
Mod SDK、全面替换旧引擎、跨平台运行和进一步玩法平衡仍未完成。
按最新要求，这轮玩法改动没有运行测试、构建或其他验证。
