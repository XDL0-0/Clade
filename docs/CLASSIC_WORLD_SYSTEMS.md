# 经典模式：动态世界与种群结算

本次实现针对首页 `/` 的经典 GPU 流水线。没有添加 V2 配方、替代地图或独立游戏入口。

## 现在怎样玩

- 在经典存档中推进回合，板块会带动地壳和陆地、淡水、两栖、近岸栖息地移动。碰撞、张裂、俯冲、火山与侵蚀改变真实海拔；后续生态计算使用这些地块。
- 全球温度、CO₂、冰量与海平面持续演化。地块温湿度、海岸、水体连通性、冰雪覆盖随之更新。区域压力保留局部作用，不再同时变成全球温差。
- 具有开花、传粉、食果等能力的物种在同地块相遇时形成共生网络。双方数量、器官匹配和接触范围限制收益。传粉影响出生，食物交换影响资源，强依赖伙伴缺失影响存活；种子散布从源地扣除、邻地增加。
- 经典回合总结新增“世界正在变化”，显示地质变化、气候状态、共生伙伴和种子传播。点伙伴名称可以打开原来的物种详情。关闭 AI 回合叙事仍保留这些数据。

## 实际接线

标准与完整模式共同使用：

`解析压力 → 读取经典地图 → 板块与地形 → 长期气候/水体 → 压力张量 → 物种与食物网 → 分层/生态位 → 生态拟真与共生 → 张量状态 → GPU死亡/竞争/移动/繁殖 → 种子传播 → 种群提交/灭绝 → 原有基因/分化 → 原有报告 → 世界动态反馈 → 原有快照/存档`

极简和调试模式仍有意省略完整世界阶段，不是经典首页的默认玩法。完整模式的额外基因、杂交、植被等阶段仍保留。

板块位置不再只是移动中心坐标：亚格位移累积后搬运地壳。长时代回合按不超过50万年的地质子步推进，合并最终地形变化；栖息地随整回合复合位移移动，多源汇聚按同物种累加。海洋种群由原有生态迁移处理。

气候按回合覆盖的时间区间计算。早期经典时代一回合为2000万或5000万年，显示长时平均态；不把一次短冰期错误地当作整段时代。温室效应、地质释气、地形风化、冰量反馈与玩家全球压力共同作用。

## 平衡修正

- 原来 GPU 已计算出生/死亡，`PopulationUpdateStage` 又从期初人口重算一次并硬裁 K。现在 GPU 路径只提交一次，保留原有灭绝规则与亲缘竞争。
- 竞争优势减少死亡，不直接凭空增加人口；出生倍率只乘一次；承载力与增长预算限制新生，死亡由死亡计算记录。
- 删除会在个体迁出后凭空补回人口的逐地块净变化夹断。扩散、迁移与种子传播使用守恒出入量；无可用迁入目标时不扣除人口。
- 最大余数法将空间人口写为整数；后续分化与灭绝结果不会被旧张量人口覆盖。
- YAML 参数接入活跃 GPU 路径。原内核硬编码容量100现在使用配置值10000；这是显著数值变化，不代表已经完成游玩调优。
- 旧的气候预迁移会提前扣人口、随后又被张量初始化补回；新世界路径保留原人口进入 GPU，以更新后的生境计算生存与移动。

- 前端 `ClassicWorldDynamics.tsx/.css`、`worldDynamics.types.ts`。

## 存档与交付边界

- 保持经典存档格式。新数据加入 `MapState.extra_data`：`classic_tectonic`、`classic_tectonic_turn`、`classic_climate`、`classic_ecology_environment_history`。旧档缺失字段时以当前地图、气候为起点初始化。
- 保存板块/地幔/火山/位移余量/随机状态与隔离历史。生态环境短历史及濒危计数随当前世界保存，避免单例串档。共生网络由当前物种和栖息地重新计算。
- 报告新增可选 `world_dynamics`；老报告无需补写。每回合仅保存动态摘要，最多24条展示连接，完整板块状态不重复加入每份回合报告。
- 为避免同回合重复推进，地质与气候各自记录已处理回合。经典整回合仍不是跨所有仓储的原子事务；本次没有宣称解决全部失败回滚问题。
- 按用户要求，没有新增或执行测试，也没有运行 lint、typecheck、构建、基准、浏览器检查或模型试请求。不能声称已验证长期稳定性、GPU编译兼容性或游玩平衡。
- 性能影响：开启此前未运行的地质与共生阶段会增加回合成本；早期长时代的地质子步更多。水体分类采用连通分量遍历，网络按实际接触建立；没有实测耗时/显存数据。经典压缩存档会增加当前板块状态体积。
- 下一步应围绕经典存档的实际游玩反馈调整容量、恢复速度、地质节奏和共生收益，不另建简化玩法。自动验证继续保持未执行，直至用户改变要求。
